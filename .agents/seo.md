# SEO guidance

Read this file only for SEO, metadata, structured data, sitemap, URL, internal-linking, or service/local-intent page work. Read `.agents/i18n.md` as well when the work affects localized routes or translated metadata.

* Treat SEO as part of the site architecture: maintain semantic, crawlable structure, meaningful hierarchy, clean URLs, appropriate metadata, and sensible internal links.
* Add service-specific or local-intent pages only when they are genuinely useful to visitors.
* Keep content user-serving. Do not create thin, duplicated, or keyword-stuffed pages merely to target search terms.
* Use only verified business facts in metadata and structured data.
